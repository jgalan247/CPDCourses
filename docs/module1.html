Module Overview

What You'll Learn

This intensive 3-hour workshop introduces teachers to practical AI tools that can transform daily work. You'll explore how artificial intelligence can save time, create differentiated resources, and support diverse learners including those with Special Educational Needs.

Learning Outcomes

✓

Identify 5-10 daily teaching tasks where AI can save time

✓

Use Brisk AI to create instant classroom resources

✓

Use Magic School AI for comprehensive lesson planning

✓

Create differentiated resources for diverse learners

✓

Apply ethical AI practices in educational contexts

✓

Evaluate AI-generated content for accuracy

Tools You'll Master

Brisk AI

Chrome extension for quick classroom tools and instant resource creation

Magic School AI

Comprehensive platform for lesson planning, assessments, and differentiation
