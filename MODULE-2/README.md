# Module 2: AI for Assessment & Feedback

**Duration:** 3 hours
**Audience:** Teachers (all levels, all subjects)
**Format:** Interactive workshop with hands-on practice
**Delivery Mode:** Face-to-face or online
**Prerequisite:** Module 1 or basic familiarity with AI tools

## Module Overview

This intensive 3-hour workshop helps teachers transform their assessment and feedback practices using AI. Building on the resource creation skills from Module 1, participants will explore how artificial intelligence can provide timely, personalized feedback, create varied assessments, and analyze student work efficiently.

### What Makes This Workshop Different?

🎯 **Assessment-Focused** - Move beyond resource creation to actual student evaluation
📊 **Data-Driven** - Learn to analyze student work and identify patterns
💬 **Feedback at Scale** - Provide quality feedback without burning out
🎨 **Multiple Assessment Types** - Quizzes, rubrics, oral assessments, projects
⚖️ **Ethics-Centered** - Navigate AI assessment with integrity
🚀 **Practical Applications** - Create assessments you'll use immediately

## Learning Outcomes

By the end of this module, participants will be able to:

1. **Create** diverse assessment types using AI (formative, summative, diagnostic)
2. **Generate** personalized feedback for student work efficiently
3. **Design** rubrics and success criteria using AI tools
4. **Analyze** student work patterns and identify learning gaps
5. **Use** AI for oral assessment preparation and marking support
6. **Apply** ethical AI practices in high-stakes assessment contexts
7. **Evaluate** the appropriateness of AI-generated assessments
8. **Adapt** feedback for different student needs and learning styles

## Pre-Workshop Preparation

### For Facilitators
1. Review the [Facilitator Guide](./facilitator-guide/Facilitator-Notes.md)
2. Create accounts on Quizizz, Magic School AI, and other featured tools
3. Prepare sample student work for analysis demonstrations
4. Test all demonstrations on the presentation setup
5. Print handouts or prepare digital distribution
6. Set up collaborative spaces (Padlet, Jamboard, etc.)

### For Participants
**Email this to participants 1 week before:**

> Please complete these simple steps before the workshop:
> 1. Complete Module 1 or ensure you're familiar with basic AI tools (ChatGPT, Magic School AI, etc.)
> 2. Create a free account at [Quizizz](https://quizizz.com/)
> 3. Bring samples of student work you need to assess (anonymized)
> 4. Complete the [Pre-Workshop Survey](./assessments/Pre-Workshop-Survey.md) (5 mins)
> 5. Think about your biggest assessment challenge
>
> Don't worry if you can't complete these - we'll help on the day!

## Key Topics Covered

### 1. Assessment Creation
- Multiple choice and auto-graded assessments
- Short answer and extended response questions
- Project-based assessment criteria
- Diagnostic assessments
- Exit tickets and formative checks

### 2. Feedback Generation
- Personalized written feedback at scale
- Strength-based feedback approaches
- Next steps and actionable guidance
- Feedback for different assessment types
- Audio feedback preparation

### 3. Rubric & Criteria Design
- Creating detailed rubrics
- Success criteria development
- Student-friendly language
- Subject-specific assessment criteria
- Self and peer assessment tools

### 4. Work Analysis
- Pattern identification in student responses
- Common misconception detection
- Progress tracking
- Gap analysis
- Differentiated next steps based on assessment data

### 5. Ethics & Best Practices
- Academic integrity considerations
- Bias in AI assessment
- Human oversight requirements
- Transparency with students and parents
- Data privacy and security
