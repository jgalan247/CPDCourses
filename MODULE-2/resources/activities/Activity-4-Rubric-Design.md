# Activity 4: Rubric Design Studio

**Duration:** 15 minutes
**Format:** Hands-on creation workshop
**Objective:** Create comprehensive, clear rubrics for upcoming assessments using AI

---

## Activity Overview

Participants design detailed rubrics and success criteria using AI tools, dramatically reducing the time usually spent creating these essential assessment tools while ensuring clarity and comprehensiveness.

## Learning Outcomes

By the end of this activity, participants will be able to:
- Generate detailed rubrics aligned to learning objectives
- Create student-friendly success criteria
- Design rubrics for various assessment types
- Adapt rubrics to school/department formats
- Create self and peer assessment tools

---

## Activity Instructions

### Part 1: Rubric Design Demonstration (5 mins)

**Facilitator Live Demo:**

**Scenario:** Creating a rubric for a Year 9 Geography fieldwork project

**Step 1: Define the Assessment**
```
Assignment: Year 9 Geography - Coastal Erosion Fieldwork Report
Length: 1500 words
Key components:
- Research question and hypothesis
- Methodology description
- Data collection and presentation
- Analysis and interpretation
- Conclusion and evaluation
```

**Step 2: Create the Prompt**
```
Create a detailed rubric for a Year 9 Geography fieldwork report on coastal erosion.

Assessment components:
1. Research question and hypothesis (20%)
2. Methodology (20%)
3. Data collection and presentation (20%)
4. Analysis and interpretation (25%)
5. Conclusion and evaluation (15%)

Rubric format:
- 4 levels: Emerging (1), Developing (2), Secure (3), Advanced (4)
- For each component, provide clear descriptors for each level
- Use specific, observable criteria
- Avoid vague language like "good" or "adequate"
- Make descriptors student-friendly
- Focus on what IS present, not what's missing
```

**Step 3: Review AI Output**
Show generated rubric on screen

**Step 4: Refine**
Demonstrate editing:
- "This descriptor is too vague. Let me make it specific..."
- "This uses complex language. I'll simplify for Year 9..."
- "This level difference isn't clear. Let me adjust..."

**Step 5: Create Student Version**
```
Convert this rubric into a student-friendly checklist using "I can..." statements.
Organize by the 4 levels.
Make it clear and encouraging.
```

**Facilitator Emphasis:**
"From task description to final rubric: 5 minutes. Traditional approach: 30-60 minutes. And this version is often MORE detailed than what we'd create manually!"

## Subject-Specific Prompt Templates

### Science: Lab Report/Practical Work

```
Create a detailed rubric for a Year [X] science [practical/investigation/report] on [topic].

Assessment components:
- Hypothesis/prediction
- Method and variables
- Results and data recording
- Analysis and interpretation
- Conclusion and evaluation
- Scientific communication

Format: 4-point scale (Emerging, Developing, Secure, Advanced)
Make descriptors specific to science skills.
Include both content understanding and scientific process.
```

**Example Descriptor Quality:**

❌ Vague: "Good hypothesis"
✅ Specific: "Hypothesis clearly states the relationship between independent and dependent variables with scientific reasoning"

### Mathematics: Problem-Solving

```
Create a rubric for assessing Year [X] mathematics problem-solving on [topic].

Assessment components:
- Understanding the problem (10%)
- Strategy selection (20%)
- Method accuracy (30%)
- Working shown (20%)
- Answer and checking (20%)

Format: 3-level rubric (Working Towards, Expected, Greater Depth)
Focus on mathematical thinking, not just correct answers.
Value process as well as product.
```

### English: Essay Writing

```
Create a detailed rubric for Year [X] [essay type] on [text/topic].

Assessment components:
- Thesis/argument clarity (20%)
- Evidence selection and use (25%)
- Analysis and interpretation (30%)
- Structure and coherence (15%)
- Technical accuracy (10%)

Format: 4-point scale with clear progression between levels
Use student-friendly language
Emphasize what strong work DOES, not what weak work lacks
```

## Rubric Format Options

### Format 1: Analytic Rubric (Most Common)

**Structure:**
- Multiple criteria (rows)
- Multiple performance levels (columns)
- Specific descriptor in each cell

**Best for:**
- Complex assignments with multiple components
- When detailed feedback is needed
- Assignments with clear, separate criteria

**AI Prompt Addition:**
"Create an analytic rubric with [number] criteria and [number] levels."

### Format 2: Single-Point Rubric

**Structure:**
- Central column: criteria/expectations
- Left column: evidence of learning/exceeding
- Right column: areas for growth/not yet meeting

**Best for:**
- Focusing on personalized feedback
- Avoiding labeling students
- Encouraging growth mindset

**AI Prompt Addition:**
"Create a single-point rubric format with criteria in the center, space for feedback on both sides."

### Format 3: Holistic Rubric

**Structure:**
- One overall performance description per level
- Considers work as a whole
- Fewer levels (typically 3-4)

**Best for:**
- Assessing overall quality
- When criteria are interrelated
- Quick marking needed

**AI Prompt Addition:**
"Create a holistic rubric with [number] levels describing overall performance."

### Format 4: Developmental/Skills Progression Rubric

**Structure:**
- Shows skill development over time
- Focuses on growth and next steps
- Often used for multiple assignments

**Best for:**
- Tracking progress
- Skills-based subjects
- Portfolio assessment

**AI Prompt Addition:**
"Create a developmental rubric showing skill progression from novice to expert in [skill]."

## Creating Student-Friendly Versions

### Why It Matters:
- Students can self-assess
- Clear expectations reduce anxiety
- Enables peer assessment
- Promotes metacognition

### Conversion Process:

**Original Rubric Language:**
"Demonstrates comprehensive understanding of [concept] with detailed, accurate explanations supported by relevant evidence."

**Student-Friendly Version:**
"I can:
- Explain [concept] in detail
- Give accurate information
- Use examples to support my points"

**AI Prompt for Conversion:**
```
Convert this rubric into student-friendly "I can..." statements.
Organize by performance level (e.g., "I'm working towards..." / "I can..." / "I can confidently...")
Use simple language appropriate for Year [X]
Make it encouraging and clear
```

## Quick Refinement Checklist

**Before finalizing your rubric, check:**

**Clarity:**
- [ ] Each descriptor is specific and observable
- [ ] Avoids vague terms ("good," "appropriate," "adequate")
- [ ] Clear difference between levels
- [ ] Student would understand expectations

**Alignment:**
- [ ] Matches learning objectives
- [ ] Reflects what was taught
- [ ] Appropriate difficulty for year group
- [ ] Covers all key assessment components

**Usability:**
- [ ] Reasonable number of criteria (4-6 typically)
- [ ] Manageable number of levels (3-5 typically)
- [ ] Easy to use for marking
- [ ] Fits on 1-2 pages

**Fairness:**
- [ ] Criteria are accessible to all students
- [ ] No cultural bias
- [ ] Values different types of strength
- [ ] Focuses on learning, not presentation (unless that's the skill)

## Gallery Walk & Peer Feedback (Last 2-3 mins)

**Activity:**

**Option A: Physical Gallery Walk**
1. Post rubrics around room (or on tables)
2. Participants walk and view others' work (5 mins)
3. Leave post-it note feedback:
   - ⭐ One strength
   - 💡 One suggestion

**Option B: Digital Sharing**
1. Upload to shared Padlet/Google Doc
2. Browse others' rubrics
3. Add comments

**Option C: Pair-Share**
1. Pair with someone from different subject
2. Exchange rubrics
3. Give feedback:
   - What's clear?
   - What could be more specific?
   - Would a student understand this?

**Whole Group Debrief:**
- Facilitator highlights 2-3 excellent examples
- Discuss: "What made these rubrics effective?"
- Ask: "Who created something they'll use this week?"

## Common Challenges & Solutions

| Challenge | Solution |
|-----------|----------|
| Descriptors too vague | Ask AI to "make each descriptor more specific and observable" |
| Levels too similar | Request: "Increase differentiation between levels" |
| Language too complex | "Simplify for Year [X] students" |
| Too many criteria | Consolidate related criteria; aim for 4-6 max |
| Doesn't match school format | Generate content with AI, then reformat to template |
| Criteria overlap | Ask AI to "clarify distinction between [criterion A] and [criterion B]" |

## Rubric Examples Across Subjects

### Science: Investigation Rubric (Excerpt)

**Criterion: Hypothesis**

| Level 1 (Emerging) | Level 2 (Developing) | Level 3 (Secure) | Level 4 (Advanced) |
|-------------------|---------------------|-----------------|-------------------|
| States a prediction without scientific reasoning | States a prediction with simple scientific reasoning | Clear hypothesis linking independent and dependent variables with scientific reasoning | Comprehensive hypothesis with scientific reasoning and reference to relevant scientific principles |

### English: Essay Rubric (Excerpt)

**Criterion: Evidence Use**

| Working Towards | Expected | Exceeding |
|----------------|----------|-----------|
| Some relevant evidence included; not always integrated into argument | Well-selected evidence integrated smoothly; supports points made | Carefully selected evidence from multiple sources; integrated seamlessly with sophisticated analysis |

### PE: Performance Rubric (Excerpt)

**Criterion: Technique**

**Emerging:** Demonstrates basic technique with frequent errors; requires significant support
**Developing:** Demonstrates correct technique in simple situations; occasional errors under pressure
**Secure:** Demonstrates correct technique consistently in varied situations
**Advanced:** Demonstrates refined technique with precision and adaptability; performs under pressure
