# Activity 5: Real Work Analysis

**Duration:** 15 minutes
**Format:** Hands-on data analysis
**Objective:** Use AI to analyze student work, identify patterns, and plan targeted instruction

---

## Activity Overview

Participants learn to use AI as a powerful pattern-recognition tool to analyze student work, identify common misconceptions, spot learning gaps, and make data-informed teaching decisions without drowning in spreadsheets.

## Learning Outcomes

By the end of this activity, participants will be able to:
- Use AI to identify common errors and misconceptions
- Analyze patterns across a class set of work
- Generate actionable teaching insights from assessment data
- Create differentiated groups based on assessment analysis
- Make evidence-based decisions about next teaching steps

---

## Privacy & Ethics Setup

### BEFORE Activity Begins

**Facilitator Must Emphasize:**

**Privacy Rules:**
- ❌ Never use real student names in AI tools
- ✅ Use codes: Student A, Student B, or S1, S2, S3
- ❌ Don't include sensitive information (SEND diagnoses, personal circumstances)
- ✅ Focus on academic responses only
- ❌ Don't share identifiable school data
- ✅ Anonymize everything

**Example Anonymization:**

**Before (Don't do this!):**
"Analyze responses from Aisha Khan (EAL, free school meals), Mohammed Ali (ADHD), and Sarah Johnson (gifted)..."

**After (Do this!):**
"Analyze responses from:
- Student A (EAL learner)
- Student B (needs attention support)
- Student C (working above year level)"

## Activity Instructions

### Part 1: Demonstration - Exit Ticket Analysis (5 mins)

**Facilitator Live Demo:**

**Scenario:** Analyzing exit tickets from a Year 8 Science lesson on photosynthesis

**Sample Data (Show on Screen):**
```
Question: "What are the inputs and outputs of photosynthesis?"

Student responses (25 students):
- 8 students: Correctly identified CO2, water, light → glucose, oxygen
- 6 students: Identified most but confused inputs/outputs
- 5 students: Said "chlorophyll" is an output
- 4 students: Mixed up photosynthesis and respiration
- 2 students: Minimal/unclear responses
```

**Step 1: Create Analysis Prompt**
```
I'm a Year 8 Science teacher. I gave an exit ticket asking: "What are the inputs and outputs of photosynthesis?"

Here's a summary of 25 student responses:
[Paste data above]

Analyze this data and provide:
1. Overall class understanding (percentage ready to move on)
2. Top 3 misconceptions or errors
3. What this tells me about my teaching
4. Specific suggestions for my next lesson
5. Differentiation grouping recommendations

Be specific and actionable.
```

**Step 2: Review AI Analysis**
Show generated response on screen

**Example AI Output:**
```
**Class Understanding:** Approximately 32% (8/25) demonstrate secure understanding. 24% (6/25) have partial understanding. 44% show significant gaps.

**Top 3 Misconceptions:**
1. **Chlorophyll confusion (20%):** Students think chlorophyll is a product rather than a catalyst
2. **Process reversal (16%):** Confusing photosynthesis with respiration - mixing up inputs/outputs
3. **Incomplete understanding (24%):** Know some components but can't distinguish inputs from outputs

**Teaching Insights:**
- The term "chlorophyll" needs clarification - students may remember it from the lesson but don't understand its role
- Input/output concept needs visual reinforcement (diagram emphasis)
- Possible that photosynthesis and respiration were taught close together, causing confusion

**Next Lesson Suggestions:**
1. Start with retrieval: Quick diagram of photosynthesis WITH LABELS "IN" and "OUT"
2. Address chlorophyll: "It helps but doesn't get used up - like a factory worker, not an ingredient"
3. Create comparison table: Photosynthesis vs. Respiration side-by-side
4. Re-assess with different question format to check understanding

**Differentiation Groups:**
- **Secure Group (8 students):** Extension - Why do plants need both photosynthesis and respiration?
- **Developing Group (6 students):** Guided practice with graphic organizer for inputs/outputs
- **Support Group (11 students):** Direct instruction on inputs/outputs with visual supports; address specific misconceptions
```

**Step 3: Turn Insights into Action**
Demonstrate planning next lesson based on this analysis:

"Based on this analysis, tomorrow I will:
- Spend 10 minutes re-teaching chlorophyll's role
- Use a Venn diagram to compare photosynthesis and respiration
- Use differentiated group work for practice
- Re-assess with a different question format at the end"

**Facilitator Emphasis:**
"This analysis took 2 minutes. Doing this manually - reading all responses, categorizing, identifying patterns - would take 20-30 minutes. And AI often spots patterns I'd miss!"

## Subject-Specific Analysis Templates

### Science: Practical Work Analysis

```
Analyze student performance on [practical/investigation]:

Data:
- [X] students completed method correctly
- [X] students recorded results accurately
- [X] students drew appropriate conclusions
- Common errors: [list]

Provide:
1. Overall practical skills assessment
2. Most common procedural errors
3. Conceptual vs. practical skill issues
4. Suggestions for improving practical teaching
5. Which students need additional practical support
```

### Mathematics: Problem-Solving Analysis

```
Analyze Year [X] student work on [math topic]:

Results:
- [X]% got correct answer with correct method
- [X]% got correct answer with incorrect/unclear method
- [X]% got incorrect answer due to calculation errors
- [X]% got incorrect answer due to wrong method
- Common errors: [list specific mistakes]

Provide:
1. Conceptual understanding vs. calculation accuracy breakdown
2. Most common misconceptions
3. Error pattern analysis
4. Intervention recommendations
5. Extension opportunities for those who mastered it
```

### English/Humanities: Written Response Analysis

```
Analyze student short-answer responses on [topic]:

Summary of responses:
- Strong responses (meeting criteria): [number/description]
- Partial responses: [number/description]
- Weak responses: [number/description]
- Common issues: [list]

Provide:
1. Overall understanding of [concept/text]
2. Writing skill vs. content knowledge analysis
3. Common gaps in understanding
4. Teaching focus for improvement
5. Model answer elements to emphasize
```

### Languages: Assessment Analysis

```
Analyze Year [X] [language] assessment on [skill: speaking/writing/listening]:

Performance breakdown:
- Grammar accuracy: [summary]
- Vocabulary range: [summary]
- Communication effectiveness: [summary]
- Common errors: [list]

Provide:
1. Key language gaps
2. Most frequent grammar errors
3. Vocabulary development needs
4. Suggested focus for next lessons
5. Differentiation by proficiency level
```

## Advanced Analysis Techniques

### Analysis Type 1: Progress Over Time

**Use When:** You have multiple assessments on same/similar topics

**Prompt:**
```
Compare student performance across three assessments:

Assessment 1 (Week 1): [summary]
Assessment 2 (Week 3): [summary]
Assessment 3 (Week 5): [summary]

Analyze:
1. Overall progress trajectory
2. Concepts that improved
3. Persistent difficulties
4. Individual vs. class-wide patterns
5. Effectiveness of my teaching approach
```

### Analysis Type 2: Subgroup Comparison

**Use When:** You want to check if all groups are progressing

**Prompt:**
```
Compare performance between different student groups:

Group A (Higher prior attainment): [results]
Group B (Middle prior attainment): [results]
Group C (Lower prior attainment): [results]

Analyze:
1. Are all groups making progress?
2. Achievement gaps widening or closing?
3. Teaching approach effectiveness for each group
4. Differentiation recommendations
```

### Analysis Type 3: Question-Level Analysis

**Use When:** You want to know which questions/skills need reteaching

**Prompt:**
```
Analyze quiz results by question:

Q1 (Recall): [X]% correct
Q2 (Application): [X]% correct
Q3 (Analysis): [X]% correct
Q4 (Evaluation): [X]% correct

Analyze:
1. Which skill levels are secure vs. weak?
2. Bloom's taxonomy pattern (do they struggle with higher-order thinking?)
3. Question design issues (if any)
4. Teaching focus priorities
```

## Turning Analysis into Action

### Framework: SPOT Analysis

**S - Strengths:** What are students doing well?
**P - Patterns:** What trends/errors are you seeing?
**O - Opportunities:** What teaching opportunities does this reveal?
**T - Targets:** What are specific next steps?

**Example:**

**S - Strengths:**
- Students can identify inputs to photosynthesis
- 32% have complete, accurate understanding

**P - Patterns:**
- 20% think chlorophyll is an output
- Confusion between photosynthesis and respiration

**O - Opportunities:**
- Clarify catalyst vs. ingredient concept
- Create comparison chart for two processes
- Use more visual supports

**T - Targets:**
- Tomorrow: 10-min mini-lesson on chlorophyll role
- This week: Side-by-side comparison activity
- Next assessment: Different question format to recheck

## Common Pitfalls to Avoid

### Pitfall 1: Analysis Paralysis
**Problem:** Getting insights but not acting on them
**Solution:** Pick 1-2 immediate actions; save other insights for later

### Pitfall 2: Ignoring Your Expertise
**Problem:** Taking AI analysis as absolute truth
**Solution:** AI suggests; you decide based on your knowledge of students

### Pitfall 3: Over-Grouping
**Problem:** Creating too many differentiation groups to manage
**Solution:** Stick to 2-3 groups maximum

### Pitfall 4: Privacy Breaches
**Problem:** Accidentally including identifiable information
**Solution:** Double-check anonymization before inputting data

### Pitfall 5: Not Re-Assessing
**Problem:** Making changes but not checking if they worked
**Solution:** Plan follow-up assessment to check impact

- AI suggests; teacher decides and acts
