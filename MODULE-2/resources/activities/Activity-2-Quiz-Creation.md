# Activity 2: AI-Powered Quiz Creation

**Duration:** 15 minutes
**Format:** Hands-on creation
**Objective:** Create at least 2 assessments using AI tools

---

## Activity Overview

Participants get hands-on experience creating quizzes, tests, and formative assessments using AI tools. By the end, everyone will have created resources they can use immediately in their teaching.

## Learning Outcomes

By the end of this activity, participants will be able to:
- Use Quizizz AI or Magic School AI to generate quizzes
- Create differentiated versions of assessments
- Edit and refine AI-generated questions for quality
- Export assessments in usable formats

## Activity Instructions

### Part 1: Create Your First AI Quiz (7 mins)

**Challenge 1: Formative Assessment Quiz**

**Instructions:**
1. Choose a topic you're teaching in the next 1-2 weeks
2. Open Quizizz or Magic School AI
3. Use AI to generate a 5-10 question quiz
4. Review and edit for quality
5. Save/export the quiz

**Step-by-Step Guide:**

#### Using Quizizz AI:
1. Click "Create" → "AI Quiz Generator"
2. Enter your prompt:
   ```
   Create a 7-question quiz on [topic] for [year group]
   Include: 5 multiple choice, 2 true/false
   Difficulty: Medium
   Focus on: [key concepts]
   ```
3. Review generated questions
4. Edit any that are unclear or don't fit your context
5. Add images if needed
6. Save quiz

#### Using Magic School AI:
1. Select "Assessment Generator"
2. Enter details:
   - Topic: [Your topic]
   - Year level: [Your year]
   - Number of questions: 7
   - Question types: Mixed
3. Generate
4. Review and refine
5. Export to Google Forms or download

#### Using ChatGPT (Alternative):
Prompt:
```
Create a 7-question quiz for Year [X] students on [topic].
Format: 5 multiple choice (4 options each), 2 true/false.
Include correct answers and brief explanations.
Focus on: [specific learning objectives].
```

**Facilitator Support:**
- Circulate and help with technical issues
- Model editing poor questions: "This one is too vague, let me show you..."
- Encourage specificity in prompts
- Time warning at 5 minutes: "Should be generating or refining now!"

### Part 2: Create an Exit Ticket (3 mins)

**Challenge 2: Quick Formative Check**

**Instructions:**
1. Think of your next lesson
2. Create a 2-3 question exit ticket
3. Focus on checking understanding of 1-2 key concepts

**Prompt Template:**
```
Create a 3-question exit ticket for [topic] with Year [X].
Questions should check: [specific concept 1] and [concept 2].
Keep it quick - 2 minutes for students to complete.
Include 1 multiple choice, 1 short answer, 1 emoji scale (understanding check).
```

**Examples by Subject:**

**Science (Photosynthesis):**
```
3-question exit ticket on photosynthesis for Year 7.
Check understanding of: inputs/outputs and where it occurs.
1 MCQ, 1 fill-in-the-blank, 1 self-rating scale.
```

**Math (Fractions):**
```
3-question exit ticket on multiplying fractions for Year 6.
Check: Can they solve 2 problems and identify one misconception?
Quick and practical.
```

**English (Persuasive Techniques):**
```
3-question exit ticket on persuasive writing techniques for Year 9.
Identify techniques in a short text, explain purpose of one, self-assess understanding.
```

**History (WW1 Causes):**
```
3-question exit ticket on causes of WW1 for Year 10.
Name 2 causes, explain one in detail, rate confidence in understanding.
```

### Part 3: Extension - Differentiated Versions (5 mins)

**For those who finish early:**

**Challenge 3: Create Differentiated Assessment Versions**

**Instructions:**
1. Take your first quiz
2. Create 2 additional versions:
   - **Easier version:** For students who need more support
   - **Harder version:** For students who need challenge

**Differentiation Strategies:**

**For Easier Version:**
- Simplify vocabulary
- Add more scaffolding (sentence starters, word banks)
- Include visual cues
- Reduce number of options (3 instead of 4)
- Break complex questions into smaller steps

**For Harder Version:**
- Add application/analysis questions
- Include multi-step problems
- Remove scaffolding
- Add "explain your reasoning" components
- Cross-curricular connections

**Prompt Template:**
```
Take this quiz and create an easier version for students who need support.
Adaptations: Simpler language, visual supports, 3 options instead of 4, word bank included.
```

```
Take this quiz and create a challenge version for advanced students.
Adaptations: Higher-order thinking, application questions, explain reasoning required.
```

## Quality Check: What Makes a Good AI Quiz?

### Review Checklist
Before finalizing your quiz, check:

**Content Quality:**
- [ ] Questions align with learning objectives
- [ ] Appropriate difficulty for year group
- [ ] Clear, unambiguous wording
- [ ] Correct answers are definitely correct
- [ ] Distractors (wrong answers) are plausible but clearly wrong

**Accessibility:**
- [ ] Language is appropriate for your students
- [ ] No cultural bias in examples
- [ ] Images are clear and relevant (if used)
- [ ] Suitable for EAL students or adapted version available

**Pedagogy:**
- [ ] Mix of recall and understanding questions
- [ ] Progresses from easier to harder (if appropriate)
- [ ] Provides useful diagnostic information
- [ ] Takes appropriate time to complete (1 min per question rough guide)

**Technical:**
- [ ] Exports correctly to your platform
- [ ] Images load properly
- [ ] Answer key is accurate
- [ ] Student-facing language is friendly and encouraging

## Editing AI-Generated Questions

### Common Issues & Fixes

**Issue 1: Question is too vague**
**Before:** "What is photosynthesis?"
**After:** "What are the main products of photosynthesis? Select all that apply."

**Issue 2: Answer options are too obvious**
**Before:**
- A) Oxygen
- B) Banana
- C) Television
- D) Purple

**After:**
- A) Oxygen and glucose
- B) Carbon dioxide and water
- C) Nitrogen and helium
- D) Methane and hydrogen

**Issue 3: Language too complex**
**Before:** "Elucidate the mechanism by which chlorophyll facilitates photosynthetic processes."
**After:** "Explain how chlorophyll helps plants make food."

**Issue 4: Cultural bias**
**Before:** "Which holiday comes after Easter?"
**After:** "Which season comes after spring in the UK?"

**Facilitator Tip:** Show one example of editing live. "This question isn't quite right because... Let me improve it..."

## Troubleshooting Guide

### Common Problems

| Problem | Solution |
|---------|----------|
| Tool won't load | Use ChatGPT backup prompts, copy/paste to Google Forms |
| Quiz quality is poor | Show editing examples, use more specific prompts |
| Participant stuck on topic | Suggest: "What's your next lesson? Start there." |
| Questions too easy/hard | Regenerate with adjusted difficulty prompt |
| Takes too long to generate | Start with fewer questions (5 instead of 10) |
| Participant wants analog version | Create in AI tool, export as PDF, print |
