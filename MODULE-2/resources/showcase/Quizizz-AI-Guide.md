## What is Quizizz AI?

Quizizz AI is an assessment platform that uses artificial intelligence to automatically generate engaging, curriculum-aligned quizzes from topics, documents, or URLs. It's specifically designed for education and includes gamification features that students love.

### Key Features

- **AI Quiz Generator:** Create full quizzes from topic descriptions
- **Document to Quiz:** Upload PDFs, paste URLs, or enter text to auto-generate questions
- **Differentiation:** Automatically adjust difficulty levels
- **Auto-Grading:** Instant feedback for students and teachers
- **Reports & Analytics:** Detailed performance data
- **Gamification:** Leaderboards, memes, power-ups
- **Question Bank:** Access millions of pre-made questions

## Creating Quizzes with AI

### Method 1: Topic-Based Generation

**Best for:** Creating quizzes on standard curriculum topics

**Steps:**
1. Click "Create" → "AI Quiz Generator"
2. Enter topic: *e.g., "Photosynthesis for Year 8"*
3. Set parameters:
   - Number of questions (5-20)
   - Difficulty level (Easy/Medium/Hard)
   - Question types (MCQ, True/False, Fill-in)
   - Add specific focus areas
4. Click "Generate Quiz"
5. Review questions (usually ready in 30-60 seconds)

**Customization Options:**
- Edit any question
- Change answer options
- Add images or diagrams
- Adjust point values
- Set time limits per question

### Method 2: Document/URL to Quiz

**Best for:** Creating comprehension checks from articles, textbook pages, or web resources

**Steps:**
1. Click "Create" → "From Content"
2. Choose input method:
   - Upload PDF document
   - Paste article URL
   - Copy/paste text directly
3. Quizizz analyzes content
4. Generates comprehension questions
5. Review and refine

**Use Cases:**
- Current events articles → quiz
- Science article → comprehension check
- Historical document → source analysis
- Video transcript → understanding check

### Method 3: Learning Objectives to Quiz

**Best for:** Aligning precisely to what you taught

**Steps:**
1. Enter specific learning objectives
2. Quizizz creates questions targeting those objectives
3. Ensures assessment matches teaching

**Example:**
```
Learning Objectives:
- Identify the reactants and products of photosynthesis
- Explain the role of chlorophyll
- Describe where photosynthesis occurs in a plant
```
Generates targeted questions for each objective.

## Tips for Quality AI-Generated Quizzes

### Do's:
✅ Be specific in your topic prompt
✅ Always review and edit questions
✅ Check answer options for plausibility
✅ Add images where helpful
✅ Test the quiz yourself before assigning
✅ Mix question types for engagement

### Don'ts:
❌ Use without reviewing (always check quality)
❌ Make quizzes too long (student fatigue sets in)
❌ Rely only on recall questions (add application too)
❌ Forget to align to what you actually taught
❌ Use for high-stakes summative without human review

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Questions don't match curriculum | Edit prompt to specify curriculum/exam board |
| Too easy/hard | Regenerate with adjusted difficulty setting |
| Poor question quality | Be more specific in prompt; edit generated questions |
| Students can't join | Check quiz is "live" and code is correct |
| Questions too text-heavy | Add images; break into shorter chunks |

## Time-Saving Workflows

### Weekly Formative Check (10 mins prep time)
1. Monday: Generate 5-question quiz on last week's topic (3 mins)
2. Review and adjust (5 mins)
3. Assign as homework mode (2 mins)
4. Friday: Review data, plan next week

### Exit Ticket Routine (5 mins prep time)
1. End of lesson: Generate 2-3 questions (2 mins)
2. Students complete on devices (5 mins)
3. Review results immediately (3 mins)
4. Adjust tomorrow's lesson

### Differentiated Practice (15 mins prep time)
1. Create standard quiz (5 mins)
2. Generate easier version (3 mins)
3. Generate harder version (3 mins)
4. Assign appropriate version to each group (4 mins)

## Ethical Considerations

**Question Accuracy:**
- AI can make factual errors → Always review
- Check answers are definitively correct
- Ensure distractors are plausible but wrong

**Academic Integrity:**
- Students could use AI to find answers
- Use for formative (practice), not high-stakes summative
- Or use supervised/timed conditions

**Equity:**
- Requires device access
- Ensure paper alternative available if needed
- Check readability for EAL students
