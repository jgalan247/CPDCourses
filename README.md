# CPD Courses - AI Tools for Teachers

Welcome to the AI Tools for Teachers CPD (Continuing Professional Development) course repository. This repository contains comprehensive workshop materials designed to help educators leverage artificial intelligence in their daily teaching practice.

## Overview

This CPD programme helps teachers discover and implement AI tools that can:
- Save time on administrative tasks and assessment workload
- Create engaging, differentiated resources
- Provide personalized feedback at scale
- Support diverse learners including those with SEND needs
- Analyze student work to inform teaching decisions
- Enhance teaching practice through intelligent automation

## Available Modules

### Module 1: AI for Daily Tasks & Resource Creation (3 hours)
**Audience:** Teachers (all levels)

**Learning Outcomes:**
- Understand how AI can assist with day-to-day teaching tasks
- Create differentiated resources for diverse learners (Autism, Dyslexia, EAL, etc.)
- Confidently use Brisk AI and Magic School AI
- Apply AI tools to real classroom scenarios

**Topics Covered:**
- Introduction to AI in Education
- Brisk AI for Chrome - Quick classroom tools
- Magic School AI - Comprehensive lesson planning
- Differentiation strategies using AI
- Hands-on practical activities
- Ethics and best practices

[📁 Access Module 1 Materials](./MODULE-1/)

### Module 2: AI for Assessment & Feedback (3 hours)
**Audience:** Teachers (all levels)
**Prerequisite:** Module 1 or basic AI familiarity

**Learning Outcomes:**
- Create diverse assessments using AI (formative, summative, diagnostic)
- Generate personalized feedback for student work efficiently
- Design comprehensive rubrics and success criteria
- Analyze student work patterns to identify learning gaps
- Apply ethical AI practices in high-stakes assessment contexts
- Evaluate the appropriateness of AI-generated assessments

**Topics Covered:**
- AI-powered quiz and test creation (Quizizz AI)
- Feedback generation at scale
- Rubric design and success criteria
- Student work analysis for teaching insights
- Assessment ethics and transparency
- Hands-on practical applications
