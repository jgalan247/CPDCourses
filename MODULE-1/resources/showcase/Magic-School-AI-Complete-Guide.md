## Top 25 Magic School AI Tools

### 📚 LESSON PLANNING TOOLS

#### 1. Comprehensive Lesson Plan Generator
**What it does:** Creates complete, detailed lesson plans

**Input required:**
- Topic/learning objective
- Year/grade level
- Duration (30-90 minutes)
- Teaching style preferences
- Prior knowledge assumptions

**Output includes:**


## Tips for Getting the Best Results

### 1. Be Specific with Input
**Vague:** "Create a lesson on animals"
**Specific:** "Create a 60-minute Year 3 Science lesson on animal habitats, focusing on UK animals, using hands-on activities"

**Better input = better output**

### 2. Include Context
Always mention:
- Year/age group
- Prior knowledge
- Your teaching style
- Class dynamics (if relevant)

### 3. Iterate and Refine
- Generate once
- Review
- Regenerate with adjustments if needed
- Use the "regenerate" button for alternatives

### 4. Combine Tools
Use multiple Magic School tools for comprehensive resources:
- Lesson Plan + Assessment + Rubric = Complete unit
- Report Comment + Email = Full parent communication
- Accommodation Suggestions + Text Leveler = Inclusive lesson

### 5. Save and Organize
- Use meaningful names for saved items
- Create folders in your drive
- Export immediately after creation

### 6. Always Personalize
- Add your examples
- Include student names (privacy-appropriate)
- Reflect your school context
- Add your teaching personality

### 7. Fact-Check
- Especially for Science, Maths, History
- Verify curriculum alignment
- Check cultural sensitivity

## Common Questions

**Q: Is Magic School only for certain subjects?**
A: No - tools work across all subjects. Some are subject-specific, most are universal.

**Q: Can I use it for UK curriculum?**
A: Yes! You can specify UK National Curriculum, GCSE, A-Level. Magic School supports international curricula.

**Q: How accurate is the content?**
A: Generally very good, but ALWAYS fact-check, especially Science, Maths, and History.

**Q: Can students access Magic School?**
A: It's designed for teachers. Student access depends on school policy and tool selection.

**Q: Is my data private?**
A: Magic School has education-focused privacy. Don't input identifiable student data. Review privacy policy.

**Q: Does it integrate with Google Classroom/Teams?**
A: Not directly integrated, but you can export and upload easily.

**Q: Can I edit outputs?**
A: Yes! Everything is editable. Export to Docs/Word and customize.

**Q: What if I don't like the output?**
