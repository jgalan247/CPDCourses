## Quick Reference

### Brisk AI - Top 5 Tools
1. **Create Quiz:** From any webpage
2. **Change Reading Level:** Differentiate text
3. **Learning Objectives:** SMART goals
4. **Discussion Questions:** Engage students
5. **Email Templates:** Parent communication

### Magic School AI - Top 5 Tools
1. **Lesson Plan Generator:** Comprehensive lessons
2. **Assessment Generator:** Tests with mark schemes
3. **Accommodation Suggestions:** SEND support
4. **Report Card Comments:** Professional feedback
5. **Rubric Generator:** Clear success criteria
