# Differentiation with AI: Master Guide

**Purpose:** This guide shows how AI can transform differentiation from time-consuming to manageable, making inclusive teaching sustainable.

---

## The Differentiation Challenge

### Traditional Approach
- **Time:** 30-60 minutes per resource to create 3 versions
- **Energy:** Exhausting to maintain consistency
- **Research:** Requires deep knowledge of every need
- **Result:** Often skipped due to time pressure

### AI-Powered Approach
- **Time:** 5-10 minutes for 5 versions
- **Energy:** Sustainable and consistent
- **Research:** AI implements research-based strategies
- **Result:** Inclusion becomes realistic

**Transformation:** From "I wish I could" to "I do this every lesson"

---

## Core Principles

### 1. Access, Not Lowering Standards
**Same learning objectives, different routes**

❌ **Wrong:** Making content "easier" for SEND students
✅ **Right:** Providing support to access the same learning

**Example:**
- **Objective:** "Analyse the causes of WWI"
- **All students:** Same objective
- **Difference:** How they access information and express understanding

### 2. Strength-Based Approach
Focus on what students CAN do with support

**Example - Dyslexic learner:**
- Challenge: Reading dense text
- Strength: Often strong verbal reasoning
- Solution: Audio support + verbal discussion options

### 3. Multiple Means of:
- **Representation:** How content is presented
- **Engagement:** How students interact
- **Expression:** How students show understanding

## Using AI for Differentiation

### Step 1: Start with Quality Core Content
Create or find your standard-level resource first.

### Step 2: Use Specific Prompts
Generic prompts = generic outputs
Specific prompts = targeted, useful adaptations

### Step 3: Review with Expertise
AI suggests, YOU decide. Check against best practice.

### Step 4: Test and Refine
Use with students, gather feedback, improve.

## Prompt Template Library

### General Differentiation Prompt
```
Adapt [this resource] for [student need] in [year group].

Student context: [specific challenges and strengths]

Please include:
- [Specific adaptations needed]
- [Type of support required]
- [Format preferences]

Maintain the same learning objectives.
```

### For Multiple Versions at Once
```
Create 3 versions of [this task] for Year [X]:

1. Foundation: For students who need significant support
   - Include: [specific scaffolds]

2. Core: For students working at expected level
   - Include: [appropriate challenge]

3. Extension: For students ready for greater challenge
   - Include: [higher-order thinking, independence]

All versions should address: [learning objective]
```

## Six Key Learner Profiles

### 1. 🧩 Autistic Learners
**Key Needs:** Structure, clarity, predictability, literal language

**AI Prompt Formula:**
```
Adapt for autistic learner, Year [X]:
- Use clear, literal language (no idioms)
- Provide visual structure and supports
- Break into explicit steps
- Reduce sensory overload
- Include processing time
- Offer concrete examples
```

**Typical Adaptations AI Will Make:**
- Visual schedules
- Numbered step-by-step instructions
- Reduced visual clutter
- Clear beginning/middle/end structure
- Literal language throughout
- Concrete rather than abstract examples

**See:** [Autism-Resources.md](./Autism-Resources.md) for detailed examples

---

### 2. 📖 Dyslexic Learners
**Key Needs:** Text accessibility, reduced cognitive load, multi-sensory

**AI Prompt Formula:**
```
Rewrite for dyslexic learner, Year [X]:
- Dyslexia-friendly font and formatting
- Increased spacing (1.5 or double)
- Short sentences and paragraphs
- Bullet points for lists
- Highlight key vocabulary
- Chunked information
Maintain same content and objectives.
```

**Typical Adaptations AI Will Make:**
- Font recommendations (OpenDyslexic, Comic Sans, Arial)
- Increased line and letter spacing
- Text broken into chunks with clear headings
- Key words in bold
- Bullet points instead of dense paragraphs
- Visual support diagrams

**See:** [Dyslexia-Resources.md](./Dyslexia-Resources.md) for detailed examples

---

### 3. 🌍 EAL (English as Additional Language) Students
**Key Needs:** Vocabulary support, simplified language, visual aids

**AI Prompt Formula:**
```
Adapt for EAL student with [beginner/intermediate/advanced] English, Year [X]:
- Simplify vocabulary (replace complex words)
- Add visual supports
- Provide sentence stems for writing/speaking
- Include glossary of key terms with simple definitions
- Explain cultural references
- Use clear, short sentences
Maintain academic rigor.
```

**Typical Adaptations AI Will Make:**
- Simplified vocabulary with alternatives
- Visual glossary
- Sentence stems: "I think...", "This shows..."
- Cultural context explanations
- Dual-language key terms (if specified)
- Picture support

**See:** [EAL-Resources.md](./EAL-Resources.md) for detailed examples

---

### 4. 🎯 Students with ADHD
**Key Needs:** Short tasks, movement, clear goals, engagement

**AI Prompt Formula:**
```
Redesign for student with ADHD, Year [X]:
- Break into short tasks (5-10 minute chunks)
- Include movement breaks
- Add visual timers and progress tracking
- Use gamification elements
- Provide immediate, concrete goals
- Reduce visual distractions
- Create clear task boundaries
```

**Typical Adaptations AI Will Make:**
- Long tasks broken into 3-5 shorter tasks
- Movement break suggestions
- Visual checklists
- Timer recommendations
- Gamification (points, levels, challenges)
- Clear start/finish for each section

**See:** [ADHD-Resources.md](./ADHD-Resources.md) for detailed examples

---

### 5. ⭐ Gifted & Talented Students
**Key Needs:** Challenge, depth, independence, creativity

**AI Prompt Formula:**
```
Extend for gifted student, Year [X]:
- Add open-ended, challenging questions
- Include independent research opportunities
- Create cross-curricular links to [subjects]
- Provide creative application tasks
- Encourage higher-order thinking (analysis, evaluation, creation)
- Offer choice and autonomy
Connect to core objectives: [state objectives]
```

**Typical Adaptations AI Will Make:**
- "What if...?" scenarios
- Research extensions
- Cross-curricular projects
- Creative alternatives
- Philosophical questions
- Choice boards

**See:** Extension examples in individual resource files

---

### 6. 👁️👂 Sensory Impairments (Visual/Hearing)
**Key Needs:** Alternative sensory input, accessible formats

**AI Prompt Formula:**
```
Adapt for student with [visual/hearing] impairment, Year [X]:

[For visual impairment:]
- Provide audio alternatives
- Include tactile elements where possible
- Use large print, high contrast
- Ensure screen reader compatibility
- Add detailed audio descriptions

[For hearing impairment:]
- Provide visual alternatives to all audio
- Include captions and transcripts
- Use clear written instructions
- Add visual alerts/notifications
- Include British Sign Language resources (if available)
```

## Combined Needs

Many students have multiple needs. AI can handle this:

**Example Prompt:**
```
Adapt this science investigation for a Year 8 student who is:
- Dyslexic
- EAL (intermediate English)
- Highly capable in practical science

Provide:
- Simplified, dyslexia-friendly text format
- Visual supports and simplified vocabulary for EAL
- Extension challenges in the practical work
```

**AI will combine strategies from multiple profiles.**

## Quality Checklist

After generating differentiated resources, check:

### Content Quality
- [ ] Learning objectives remain the same
- [ ] Content is factually accurate
- [ ] Age-appropriate
- [ ] Culturally sensitive

### Differentiation Quality
- [ ] Adaptations are specific and targeted
- [ ] Support is meaningful, not superficial
- [ ] Research-based strategies used
- [ ] Access is provided, not standards lowered

### Usability
- [ ] Clear for students to understand
- [ ] Realistic to implement in your classroom
- [ ] Professional appearance
- [ ] Ready to use or easy to adapt

### Personalization
- [ ] Reflects your students' specific needs
- [ ] Includes your school context
- [ ] Uses your teaching style
- [ ] Has your examples and language

## Real Example: Before and After

### Original Task (Year 9 History)
"Analyse the causes of World War I. Evaluate which cause was most significant and explain your reasoning using evidence from at least three sources."

---

### Version 1: Autistic Learner
**AI-Adapted:**

```
World War I Causes - Investigation Task

Step 1: Read about the causes (20 minutes)
Read the four information sheets about WWI causes:
□ Sheet 1: Alliances
□ Sheet 2: Imperialism
□ Sheet 3: Militarism
□ Sheet 4: Assassination

Step 2: Make notes (10 minutes)
Use the table provided. Write one fact about each cause.

[Visual table template shown]

Step 3: Choose the most important cause (5 minutes)
Look at your notes. Circle the cause you think is most important.

Step 4: Write your explanation (15 minutes)
Complete these sentences:

I think _____________ was the most important cause.

This is because _____________.

Evidence for this is _____________.

[Visual timeline showing causes leading to war]
```

**Adaptations made:**
- Broken into numbered steps
- Time guidance for each step
- Checkboxes for completion
- Sentence stems provided
- Visual support added
- Concrete, literal instructions

### Version 5: Gifted & Talented Extension
**AI-Adapted:**

```
World War I Causes: Extended Analysis

Core Task:
Analyse the causes of WWI and evaluate significance.

Extension Challenges (Choose 2-3):

1. Historical Patterns
   Compare WWI causes to another major conflict (WWII, Cold War, etc.).
   What patterns do you notice? Create a visual model showing common factors in major conflicts.

2. Counterfactual History
   If you could remove ONE cause, which would prevent the war?
   Write a 500-word analysis defending your choice.
   Challenge: Consider unintended consequences.

3. Modern Parallels
   Research current international tensions.
   Which WWI causes do you see today?
   Create a presentation: "Could it happen again?"

4. Interconnection Model
   The causes didn't work alone.
   Create a diagram/model showing how they interconnected.
   Which connections were most dangerous?

5. Primary Source Investigation
   Find 3 primary sources from 1914.
   Analyse: Did people at the time understand what was happening?
   Write a comparison: Then vs. Now perspectives.

Present your findings in your choice of format:
Essay | Video | Podcast | Visual essay | Website | Your idea

Success criteria: Demonstrate analysis, evaluation, and synthesis of complex ideas.
```

**Adaptations made:**
- Open-ended challenges
- Choice and autonomy
- Cross-curricular links
- Higher-order thinking required
- Creative presentation options
- Independence expected

## Time Comparison

**Creating these 5 versions manually:**
- Research each need: 30-45 mins
- Adapt content 5 times: 90-120 mins
- Format and polish: 30-45 mins
**Total: 2.5-3.5 hours**

**Creating with AI:**
- Set up prompts: 5 mins
- Generate 5 versions: 5-10 mins
- Review and adapt: 15-20 mins
- Polish: 10 mins
**Total: 35-45 minutes**

**Time saved: ~2 hours per resource**

## Implementation Strategy

### Week 1: Start Small
- Differentiate ONE key resource
- Use for 2 groups (e.g., dyslexia + EAL)
- Gather student feedback

### Week 2-3: Build Skills
- Add more learner profiles
- Refine prompts based on results
- Create template prompts you can reuse

### Week 4+: Systematic Approach
- Differentiate key resources for every unit
- Build a resource bank
- Share with department

---

## Sharing with Students

### Invisible Differentiation
- Provide different versions without labeling
- "Here are two versions - choose the one that works for you"
- Students self-select based on need

### Explicit Differentiation
- "I've created different access points to the same learning"
- Normalize different routes to success
- Celebrate diversity of approaches

**Either approach works - choose based on your students and school culture.**

## Ethics and Considerations

### Do:
✅ Use AI to implement research-based strategies
✅ Personalize AI outputs to YOUR students
✅ Combine AI with your professional judgment
✅ Fact-check adaptations
✅ Involve students in feedback

### Don't:
❌ Use AI as replacement for knowing your students
❌ Input identifiable student data
❌ Accept outputs without review
❌ Forget that you're the expert
❌ Use AI-generated IEPs without professional oversight
