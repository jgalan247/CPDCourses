# Module 1: AI Tools for Daily Tasks & Resource Creation

**Duration:** 3 hours
**Audience:** Teachers (all levels, all subjects)
**Format:** Interactive workshop with hands-on practice
**Delivery Mode:** Face-to-face or online

## Module Overview

This intensive 3-hour workshop introduces teachers to practical AI tools that can transform their daily work. Participants will explore how artificial intelligence can save time, create differentiated resources, and support diverse learners including those with Special Educational Needs.

### What Makes This Workshop Different?

🎯 **Practical, Not Theoretical** - You'll create real resources you can use Monday morning
🛠️ **Hands-On** - 60% of the time is spent actually using the tools
🌟 **Showcase-Focused** - Deep dive into Brisk AI and Magic School AI
♿ **Inclusion-Centered** - Heavy focus on differentiation for SEND learners
🚀 **Interactive** - Activities, demos, and collaborative learning

## Learning Outcomes

By the end of this module, participants will be able to:

1. **Identify** 5-10 daily teaching tasks where AI can save time
2. **Use** Brisk AI to create instant classroom resources
3. **Use** Magic School AI for comprehensive lesson planning
4. **Create** differentiated resources for:
   - Autistic learners
   - Dyslexic learners
   - EAL (English as Additional Language) students
   - Students with ADHD
   - Gifted and talented students
5. **Apply** ethical AI practices in educational contexts
6. **Evaluate** AI-generated content for accuracy and appropriateness

## Pre-Workshop Preparation

### For Facilitators
1. Review the [Facilitator Guide](./facilitator-guide/Facilitator-Notes.md)
2. Create accounts on Brisk AI and Magic School AI
3. Test all demonstrations on the presentation setup
4. Print handouts or prepare digital distribution
5. Set up collaborative spaces (Padlet, Jamboard, etc.)

### For Participants
**Email this to participants 1 week before:**

> Please complete these simple steps before the workshop:
> 1. Install Chrome browser (if not already installed)
> 2. Create a free account at [Magic School AI](https://www.magicschool.ai/)
> 3. Complete the [Pre-Workshop Survey](./assessments/Pre-Workshop-Survey.md) (5 mins)
> 4. Think about one lesson or resource you'd like to create during the workshop
>
> Don't worry if you can't complete these - we'll help on the day!
