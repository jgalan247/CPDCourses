# Online Delivery Guide
## Delivering AI CPD Workshops Virtually

**Purpose:** Comprehensive guide for facilitating Modules 1, 2, and 3 online

**Last Updated:** November 2025

---

## Overview

All three CPD modules are designed to work both face-to-face and online. This guide provides specific strategies, tools, and adaptations for effective online delivery.

### What You'll Need

- **Video conferencing platform** (Zoom, Microsoft Teams, Google Meet)
- **Collaborative tools** (Padlet, Miro, Google Jamboard, Mentimeter)
- **Screen sharing capability**
- **Breakout room functionality**
- **Chat and polling features**
- **Reliable internet connection**
- **Good quality microphone/camera**

## Essential Setup (Before the Workshop)

### 1 Week Before

**Platform Setup:**
- [ ] Create meeting link (enable waiting room)
- [ ] Set up breakout rooms (pre-assign if possible)
- [ ] Enable screen sharing for participants
- [ ] Test recording settings
- [ ] Create polls in advance (if using)

**Materials Preparation:**
- [ ] Convert all handouts to digital format (Google Docs/PDFs)
- [ ] Set up collaborative boards (Padlet, Miro, Jamboard)
- [ ] Create shareable links folder (Google Drive, OneDrive)
- [ ] Prepare slide deck with hyperlinks
- [ ] Test all demo tools on screen share

**Participant Communication:**
- [ ] Send joining instructions with link
- [ ] Tech check recommendations (camera, mic, browser)
- [ ] Pre-workshop task reminders
- [ ] Request participants join 5 mins early for tech check

**Example Email:**

```
Subject: Online Workshop - Tech Setup & Joining Instructions

Dear Participants,

Your AI CPD workshop is online! Here's what you need:

JOINING DETAILS:
Date: [Date]
Time: [Time]
Zoom Link: [Link]

Password: [Password]

BEFORE THE SESSION:
- Test your camera and microphone
- Use Chrome or Edge browser (for best tool compatibility)
- Join 5 minutes early for tech check
- Have a second device/screen handy (helpful but not essential)

ACCOUNTS TO CREATE:
- [List any tools they need accounts for]

MATERIALS:
All workshop materials: [Google Drive link]

See you online!
[Your Name]
```

## Online Facilitation Strategies

### Engagement Techniques

**Challenge:** Keeping energy high and participants engaged online

**Solutions:**

**1. Frequent Interaction (Every 5-10 Minutes)**
- Quick polls
- Chat responses
- Reactions (thumbs up, hand raise)
- "Type in chat if you..."
- "Raise hand if you..."

**2. Visual Variety**
- Alternate between: slides, screen shares, collaborative boards, your face
- Use visually engaging slides
- Share screen with participants' work visible

**3. Breakout Rooms**
- Use liberally for activities
- Pre-assign (if you know participants)
- Give clear instructions before sending
- Set timer visible to participants
- Visit rooms to check in

**4. The Chat**
- Encourage use throughout
- Assign a co-facilitator to monitor chat (if possible)
- Acknowledge chat contributions verbally
- Use for quick questions, links, sharing

**5. Cameras On**
- Encourage (but don't mandate - accessibility)
- Model: Your camera always on
- "Cameras on for breakout work helps collaboration"

## Activity Adaptations for Online

### Module 1: AI Tools for Daily Tasks

#### Activity 1: AI Icebreaker Challenge
**Face-to-Face:** Pairs, share verbally
**Online Adaptation:**
- **Option A:** Breakout rooms (pairs), 5 mins, come back and share
- **Option B:** Individual work, post to Padlet, everyone views
- **Tool:** Padlet board with columns for each pair

#### Activity 2: Brisk AI Quick Wins
**Face-to-Face:** Hands-on at own device
**Online Adaptation:**
- Works perfectly online - participants work independently
- Use Zoom gallery view to monitor progress
- Encourage chat for questions
- Share screen to help anyone stuck
- **Engagement:** "Post screenshot to chat when you complete one!"

#### Activity 3: Magic School Deep Dive
**Face-to-Face:** Independent creation
**Online Adaptation:**
- Same as Activity 2
- Optionally: Breakout rooms for subject groups to collaborate
- Share examples via screen share at end

#### Activity 4: Differentiation Workshop
**Face-to-Face:** Individual work, share at tables
**Online Adaptation:**
- Individual creation (10 mins)
- Breakout rooms (subject groups) to share (5 mins)
- Whole group: 2-3 share via screen share

#### Activity 5: Create Your Own Resources
**Face-to-Face:** Independent work, gallery walk
**Online Adaptation:**
- Independent creation
- **Instead of gallery walk:**
  - Post to shared Google Slides (one slide per person)
  - OR: Padlet board
  - OR: Quick shares in breakout rooms
- **Alternative:** "Popcorn sharing" - 30 seconds each, volunteers

### Module 2: AI for Assessment & Feedback

#### Activity 1: Assessment Type Sorting
**Face-to-Face:** Physical cards, three zones
**Online Adaptation:**
- **Tool:** Miro or Jamboard with draggable cards
- OR: Mentimeter sorting activity
- OR: Collaborative Google Slides with moveable boxes
- Participants move items collaboratively
- Debrief via video discussion

#### Activity 2: Create Your Own Assessments
**Face-to-Face:** Hands-on at devices
**Online Adaptation:**
- Works perfectly online
- Share progress in chat
- Quick screen shares of finished quizzes

#### Activity 3: Generate Feedback Workshop
**Face-to-Face:** Individual work on own student work
**Online Adaptation:**
- Same - works well online
- Breakout rooms for pair feedback on each other's drafts
- Privacy reminder: Don't share actual student names on screen

#### Activity 4: Design Your Rubrics
**Face-to-Face:** Individual creation, gallery walk
**Online Adaptation:**
- Individual creation
- Share to collaborative Google Doc (template provided)
- Breakout rooms to review each other's rubrics
- Whole group: Highlight 2-3 examples

#### Activity 5: Real Work Analysis
**Face-to-Face:** Using own data
**Online Adaptation:**
- Works perfectly online
- Screen share examples (anonymized)
- Breakout pairs to discuss insights

---

### Module 3: Student-Facing AI Tools & Digital AI Literacy

#### Activity 1: AI Literacy Skills Audit
**Face-to-Face:** Group brainstorm, flip chart
**Online Adaptation:**
- **Tool:** Padlet with 4 columns (Knowledge, Skills, Ethics, Critical Thinking)
- Everyone contributes simultaneously
- Debrief by reviewing submissions together

#### Activity 2: Student Tools Exploration
**Face-to-Face:** Hands-on exploration
**Online Adaptation:**
- Same - independent exploration
- Breakout rooms: Share findings (3 people, 5 mins)
- Reconvene: Collect insights via poll or chat

#### Activity 3: AI Literacy Lesson Design
**Face-to-Face:** Individual/pair work, share
**Online Adaptation:**
- Individual design (8 mins)
- Breakout rooms (pairs) for feedback (2 mins)
- Template in shared Google Doc

#### Activity 4: Responding to AI Misuse
**Face-to-Face:** Pair role-plays
**Online Adaptation:**
- Breakout rooms (pairs) for role-play
- Give clear scenario and roles before sending
- Debrief in main room

#### Activity 5: Design AI-Enhanced Lessons
**Face-to-Face:** Individual creation, gallery walk
**Online Adaptation:**
- Individual creation
- Share to Padlet/Google Slides
- Breakout rooms to discuss in small groups
- Highlight examples in main room

## Screen Sharing Tips

### When to Share Your Screen
- Demonstrating tools
- Showing examples
- Walking through steps
- Highlighting resources

### When to Switch Back to Gallery View
- Discussions
- Breakout room instructions
- Q&A
- Reflection moments

### Best Practices
- Close unnecessary tabs/apps (avoid distractions)
- Increase browser zoom (125-150%) for visibility
- Narrate what you're doing: "I'm clicking on..."
- Pause for questions
- Ask: "Can everyone see my screen clearly?"

### Common Issues
**Screen share freezes:** Re-share or switch presenter
**Participants can't hear demo audio:** Share with "Share computer sound" checked
**Screen too small for participants:** Increase zoom, use full screen mode

## Breakout Room Strategy

### When to Use
- Pair/small group discussions (2-4 people)
- Collaborative activities
- Practice scenarios
- Peer feedback

### Setup
**Pre-Assign Breakout Rooms:**
- Good for mixing subject areas
- Balance experience levels
- Requires knowing participants

**Auto-Assign Breakout Rooms:**
- Good for variety
- Quick setup
- Random groupings

**Let Participants Choose Rooms:**
- Good for subject-specific discussions
- Self-selection

### Instructions
**Before Sending to Rooms:**
1. Explain task clearly (show on screen)
2. Give time allocation
3. Identify roles (if needed): timekeeper, note-taker, reporter
4. Share any links/resources needed
5. Set expectations for what to do when they return

**Example:**
"In breakout rooms (5 minutes):
- Introduce yourselves briefly
- Person with longest commute goes first
- Share one AI tool you explored
- Discuss: How could students misuse it?
- Be ready to share one insight when we return"

### During Breakouts
- Visit rooms to check in (use "Join" feature)
- Send broadcast message with time warnings: "2 minutes left!"
- Be ready to extend time if needed
- Have backup plan if rooms fail (use chat discussion instead)

### After Breakouts
- Welcome everyone back
- Give 30 seconds to settle
- Debrief: "What came up in your discussions?"
- Call on specific rooms if needed

## Engagement Strategies for Online Delivery

### The First 10 Minutes (Critical!)

**Goal:** Get everyone participating immediately

**Strategy:**
1. **Welcome individually** as they join (name them!)
2. **Quick tech check:** "Give me a thumbs up if you can hear me"
3. **Chat warm-up:** "Type in chat: Your name, subject, one word for how you feel about AI"
4. **Set norms:**
   - Cameras encouraged
   - Mute when not speaking
   - Use chat actively
   - Raise hand for questions
5. **First activity within 10 minutes** - get them DOING something

---

### Maintaining Energy (Throughout)

**Every 15-20 Minutes, Change Something:**
- Mode: Presentation → Activity → Discussion
- Format: Whole group → Breakout → Individual
- Visual: Slides → Screen share → Board → Gallery view
- Interaction: Poll → Chat → Video share → Breakout

**Energy Boosters:**
- Quick polls ("React with emoji...")
- Stand up stretch (seriously!)
- Chat flood ("Everyone type in chat...")
- Quick wins celebration
- Humor and enthusiasm (you set the tone!)

---

### Handling Challenges

**Low Participation:**
- Call on people by name (gently)
- Use chat to lower barrier: "Type in chat rather than speak if easier"
- Smaller breakout groups (pairs)
- Make participation routine, not special

**Technical Issues:**
- Stay calm
- Have backup plan (e.g., skip breakouts, use chat)
- Co-facilitator can help troubleshoot via chat
- "If you're having issues, stay in main room and I'll help"

**Disengaged Participants:**
- Use name: "Sarah, what's your thought on this?"
- Breakout rooms (harder to disengage)
- Ask for their subject-specific input
- Private chat check-in: "How are you doing?"

**Time Running Behind:**
- Skip one demo (provide recording later)
- Shorten breakout times
- Skip gallery walk (do quick popcorn shares)
- Extend break time

## Module-Specific Online Tips

### Module 1: AI Tools for Daily Tasks

**Challenges:**
- Demonstrating two different tools (Brisk & Magic School)
- Participants installing browser extensions
- Everyone working at different speeds

**Solutions:**
- Pre-record Brisk installation (show if needed)
- Have screenshots of each step
- Create "help breakout room" for stuck participants
- Pair fast finishers with strugglers
- Extension activity ready for early finishers

**Engagement Tips:**
- Share examples in chat as they create
- Screen share participant work (with permission)
- Celebrate: "Wow, look at this differentiation!"

---

### Module 2: AI for Assessment & Feedback

**Challenges:**
- Need anonymized student work for examples
- Detection practice requires examples
- Sensitive topic (some defensive about AI use)

**Solutions:**
- Provide sample student work beforehand
- Create "safe space" language from start
- Breakout rooms for sensitive discussions
- Emphasize "we're all learning"

**Engagement Tips:**
- Use polls for confidence ratings
- Scenarios in chat: "What would you do if..."
- Share time savings calculations (motivating!)

---

### Module 3: Student-Facing AI Tools & Digital AI Literacy

**Challenges:**
- Controversial topic (banning vs. embracing AI)
- Wide range of opinions in room
- Need to explore multiple student tools
- Emotional reactions

**Solutions:**
- Set "no judgment" norm early
- Use breakout rooms for divisive discussions
- Acknowledge multiple valid perspectives
- Focus on "what's best for students"

**Engagement Tips:**
- Poll: "Your current approach to student AI?"
- Scenarios: "A student admits to using ChatGPT..."
- Role-plays in breakouts (makes it real)
- Celebrate brave policy-making

## Time Management Online

### Online Tends to Run Longer Because:
- Tech troubleshooting
- Breakout transitions
- Slower participation (muting/unmuting)
- Screen sharing delays

### Build in Buffer Time:
- Add 5 mins to each segment
- Shorten one demo if running behind
- Have "skip if needed" activities marked

### Use Timers:
- On-screen countdown for activities
- Zoom timer feature
- Verbal time checks
- Breakout room auto-timer

## Recording the Workshop

### Should You Record?

**Pros:**
- Participants can revisit
- Miss something? Watch later
- Share with absent colleagues
- Demonstrates transparency

**Cons:**
- Less candid participation
- Privacy concerns
- File size/storage

**Best Practice:**
- Ask permission at start
- Pause recording for breakouts (privacy)
- Record demos only (not whole workshop)
- Share within 24 hours

### What to Record:
- Tool demonstrations
- Key explanations
- Ethics discussions (if comfortable)

### What NOT to Record:
- Breakout rooms (automatically not recorded)
- Participant screen shares (unless they agree)
- Q&A with sensitive questions

## Accessibility Considerations

### For Participants with Different Needs:

**Visual:**
- Describe what's on screen
- Use high contrast slides
- Increase text size on screen shares
- Provide materials in advance

**Auditory:**
- Use captions (Zoom auto-captions)
- Supplement verbal with visual/chat
- Check in via chat as well as verbally

**Neurodiversity:**
- Clear structure and timing
- Breaks honored
- Quiet spaces (camera off during breakouts OK)
- Instructions both verbal and written

**Connectivity:**
- Option to dial in (audio only)
- Record for later viewing
- Send materials in advance
- Forgive frozen screens gracefully

## Troubleshooting Common Issues

| Issue | Solution |
|-------|----------|
| "I can't hear you" | Check: Are YOU muted? Ask them to check speakers/volume |
| "I can't see your screen" | Re-share screen; ensure participant display settings |
| Breakout rooms not working | Backup: Use chat for small group discussion |
| Participant can't access tool | Screen share and guide; or partner with someone |
| Someone drops out | Send private chat; re-admit if needed; continue |
| Awkward silence after question | "Type in chat or raise hand" - lower barrier |
| Running way behind | Skip a demo; provide materials for self-study |
| Zoom bombing/disruption | Enable waiting room; remove disrupter; lock meeting |

## Final Tips for Online Success

✅ **Start with energy** - you set the tone
